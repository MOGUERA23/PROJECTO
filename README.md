InmoSystem es una aplicación web desarrollada como proyecto académico para la materia Introducción a la Ingeniería de Software de la Universidad Estatal de Milagro. El sistema permite gestionar propiedades inmobiliarias, usuarios, operaciones de contacto y reportes estadísticos desde una interfaz web intuitiva y sin necesidad de instalación.

Tecnologías utilizadas: HTML5, CSS3, JavaScript puro (sin frameworks ni librerías externas).

Cómo ejecutar el proyecto: Descargar el archivo sistema_inmobiliario_v3.html, hacer doble clic sobre el archivo y abrirlo en cualquier navegador moderno (Chrome, Firefox o Edge). El sistema no requiere conexión a internet ni instalación de software adicional.
